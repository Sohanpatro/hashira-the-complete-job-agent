# Contributing to Hashira

Thanks for helping make job searching less chaotic.

## Ways to help
- **Report a bug or confusing step:** open an issue with what you said to Hashira, what it did, and what you expected.
- **Improve a skill:** edit a `skills/*/SKILL.md`, then explain in the PR what behaviour changes and why.
- **Add templates:** Prep Library, Search Library or Playbook templates, with synthetic content only.

## Rules
1. **No personal data.** No real names, IDs, resumes, emails or employer-internal material. Use `{{PLACEHOLDERS}}` and synthetic examples.
2. **Keep the safety rules.** Approval before anything leaves, truth-only resumes, and private pay and level are core. Don't weaken them.
3. **Keep it short.** Skills are read on every run, so every line costs tokens.

## Pull requests
Fork → branch → commit → PR. Describe the change and how you tested it in a Claude session.
